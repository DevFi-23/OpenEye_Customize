# 2026-11-04: cycle baseline after row O (bugs #37, #17, #39)

`venv/bin/python tools/run_profile.py --jobs 4 --compare doc/perf/baseline_2026-11-02 --save doc/perf/baseline_2026-11-04 --report ...`
on `dev` with the fixes of `doc/experiments/2026-11-04_rowO_bug17_bug37.md` (iact buffer fields 13 bit, one input
channel without row pairs and without the Python channel padding, weight sets of one-channel layers). 12/12 PASS.

* 11 cases identical to `baseline_2026-11-02` in every phase, cycle and DMA word (also the DMA 32 case: the status
  stream keeps 28 / 14 / 7 words).
* `model_mnist_real_c1` (the real one-channel MNIST model, random data): -360 cycles (-0.2 %), -336 DMA words, all in
  Conv1 (-1.1 %): `load_iact` -96 (the padding channel is no longer sent), `load_wght` -240 (one channel of weights
  instead of two), `writeback` -24; `compute` is unchanged, the zero activations of the padding channel were skipped
  by the PEs anyway.

This is the current baseline. Report against `baseline_2026-11-02` below.
